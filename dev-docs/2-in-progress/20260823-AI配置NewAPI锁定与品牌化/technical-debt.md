# 技术债记录：AI 配置 云揽川 锁定与品牌化

> 更新日期：2026-08-27

## 已知技术债

| 编号 | 描述 | 影响 | 计划处理 |
| --- | --- | --- | --- |
| 1 | 平台白名单为硬编码常量，未来如需放开其他平台需改代码 | 平台收敛的灵活性受限 | 后续可升级为配置项 `fusion.ai.allowed-platforms` |
| 2 | 同平台唯一启用配置只在 Service 层检查，无数据库唯一约束 | 极端并发下可能短暂出现多条启用配置 | 可考虑迁移加唯一索引（本期不动迁移） |
| 3 | ComfyUI 接入仍保留在平台选项中 | 增加维护面 | 按产品决策保留；工作流能力见 ComfyUI 需求目录 |
| 4 | `/settings/ai-models` 仅在 `configs.length === 0` 时显示新建入口 | 已有云揽川后无法从 UI 再添加 ComfyUI | 按平台分别判断是否已有启用配置，缺失时显示对应入口 |
| 5 | 空状态仍引导「添加 API 配置」 | 与实际按钮文案不一致 | 改成与「配置 云揽川 接入」一致 |
| 6 | 新建配置文本协议默认 `openai_compatible` | 与图片/视频默认 `newapi` 不对称 | 产品确认后改为 `newapi` 或在计划中明确保留兼容协议 |
| 7 | `getPlatformDefaultApiUrl("newapi")` 仍返回 `https://docs.newapi.ai` | 与产品网关 `gate.xinchyun.com` 不一致 | 与种子数据一并收口，避免新用户填错地址 |

## 记录原则

- 已执行的迁移不可修改（AGENTS.md 硬约束）。
- 不引入 fallback 代码；功能缺口需完整实现并留档。
